# Zorginstituut: R-model submission guide (pilot)

Selected Dutch submission guide; the source is explicitly a pilot/draft, not a universal R standard. Zorginstituut Nederland, El Alili M et al. Factual navigation guide; the [PDF](https://english.zorginstituutnederland.nl/site/binaries/site-content/collections/documents/2022/12/15/guideline-for-building-cost-effectiveness-models-in-r/Guideline%2Bfor%2Bbuilding%2Bcost-effectiveness%2Bmodels%2Bin%2BR.pdf) labels its status “Pilot”.

Source: [Official source](https://english.zorginstituutnederland.nl/documents/2022/12/15/guideline-for-building-cost-effectiveness-models-in-r).

| Source section | Review focus |
| --- | --- |
| §§2.2–2.4 | State end-to-end scope and provide the inputs required to reproduce the submitted analysis. |
| §2.5 | Provide README, portable project, separate data/code/results, and externally readable input values with sources/ranges/distributions. |
| §2.6 | Check the prescribed R Markdown structure: installation, functions, inputs, settings, base case, sensitivity/scenario analyses and validation; VOI is optional. |
| §2.7 | Document conventions and explain code/functions clearly. |
| §2.8 | Specify R/package versions and external functions; check currently accepted package specifications for actual submissions. |
| §2.9 | Provide unit tests and validation evidence. |
| §§2.10–2.12 | Check optional features, submission procedure and matters outside the pilot’s scope. |

The [submission page](https://www.zorginstituutnederland.nl/documenten/2025/02/14/format-farmaco-economisch-dossier) links the guide and a separate package/version appendix. Consult both for Dutch submissions. Do not impose prescribed file layouts or package restrictions on unrelated research.
