# NICE economic evaluation: review guide

Selected economic-methods guide for the NICE technology-appraisal/HST context; not the complete manual. National Institute for Health and Care Excellence. Factual navigation guide; source rights retained. Section headings and numbering should be rechecked when the manual changes.

Source: [Official source](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2).

Use when NICE is the intended decision context. Check the current reference case before interpreting any deviation; do not apply England-specific assumptions universally.

| Manual section | Review focus |
| --- | --- |
| [§4.2](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#the-reference-case-framework) | Match the decision problem, comparators, perspective, evaluation type and horizon; explain reference-case departures. |
| [§4.3](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#measuring-and-valuing-health-effects-in-cost-utility-analyses) | Check outcome measurement, valuation and utility mapping. |
| [§4.4](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#evidence-on-resource-use-and-costs) | Check resource quantities, unit costs, price year and included categories. |
| [§4.5](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#discounting) | Check current discounting rules and justified exceptions. |
| [§4.6](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#modelling-methods) | Assess structure, evidence selection, extrapolation, assumptions and validation. |
| [§4.7](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#exploring-uncertainty) | Assess parameter, structural and methodological uncertainty and scenarios. |
| [§4.8](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#companion-diagnostics) | Include relevant testing pathways, costs and effects where applicable. |
| [§4.9](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#analysis-of-data-for-patient-subgroups) | Justify subgroups, heterogeneity and subgroup-specific estimates. |
| [§4.10](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#presentation-of-data-and-results) | Check inputs, disaggregated outputs, incremental comparisons and uncertainty. |
| [§4.11–4.12](https://www.nice.org.uk/process/pmg36/chapter/economic-evaluation-2#impact-on-the-nhs) | Assess implementation/resource impact and health inequalities where relevant. |

Follow the linked sections for exact applicability, current numerical assumptions and exceptions. This guide does not determine reimbursement or certify a NICE submission.

When this guide informs a review, include a visible summary/limitations note: “This review used selected NICE (England) methods; it was not a full HTA assessment.” Give the edition and link to the manual sections actually consulted. Combine with the other jurisdiction’s note if both were used.
