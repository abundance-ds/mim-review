# PRISMA-NMA 2015 checklist

All 27 main items and S1–S5 extension items; factual wording adapted. Hutton B et al., Annals of Internal Medicine 162:777–784. Checked against the [official Word checklist](https://www.prisma-statement.org/s/PRISMA-NMA-checklist.docx); source rights retained.

Source: [Official source](https://doi.org/10.7326/M14-2385).

| Original item | Requirement |
| --- | --- |
| 1 | Identify a systematic review with network meta-analysis (NMA). |
| 2 | Abstract: give objectives, sources, eligibility, participants/interventions, appraisal and synthesis methods; study/participant counts, effects with confidence/credible intervals and any rankings; limitations, implications, funding and registration. Selected comparator summaries may be used for brevity. |
| 3 | Explain the rationale and why NMA is needed. |
| 4 | Specify the question using population, interventions, comparators, outcomes and designs. |
| 5 | Locate the protocol and give registration information, if available. |
| 6 | Justify study/report eligibility. Define treatments and justify any merging into network nodes. |
| 7 | List all search sources, coverage and last search date, including author contacts. |
| 8 | Provide a reproducible electronic search for at least one database, including limits. |
| 9 | Describe screening, eligibility and inclusion in review and synthesis. |
| 10 | Describe extraction forms/piloting, independent/duplicate extraction, and investigator clarification. |
| 11 | Define sought variables, assumptions and simplifications. |
| S1 | Explain how network geometry and potential related biases were investigated; specify graphical summaries and characteristics collected. |
| 12 | Describe study/outcome bias assessment and its use in synthesis. |
| 13 | Specify effect measures and additional summaries, including rankings/SUCRA if used and presentation adaptations. |
| 14 | Describe synthesis methods for each network, including multi-arm trials, variance structure, Bayesian priors where applicable, and model fit. |
| S2 | Describe direct–indirect consistency assessment and how detected inconsistency was addressed. |
| 15 | Describe assessments of publication/selective-reporting bias across the evidence base. |
| 16 | Describe additional analyses and prespecification: sensitivity/subgroups, meta-regression, alternative networks, and Bayesian priors where applicable. |
| 17 | Give screening/eligibility/inclusion counts and exclusions with reasons; preferably use a flow diagram. |
| S3 | Show a network graph of included studies. |
| S4 | Describe evidence distribution across treatments/comparisons, trial/participant counts, gaps, and potential network-structure bias. |
| 18 | Provide each study’s extracted characteristics and citation. |
| 19 | Report study-level and available outcome-level bias assessments. |
| 20 | For each benefit/harm outcome and study, give group summaries and effects with uncertainty; adapt presentation for large networks. |
| 21 | Report every synthesis with confidence/credible intervals. Large-network main-text summaries may use a reference comparator with full results in an appendix; report additional summaries such as rankings if explored. |
| S5 | Report inconsistency investigations, including applicable model-fit comparisons, tests and network-specific estimates. |
| 22 | Report across-study bias assessments. |
| 23 | Report additional analyses performed: sensitivity/subgroups, meta-regression, alternative networks and priors as applicable. |
| 24 | Summarise findings and strength of evidence by main outcome, including stakeholder relevance. |
| 25 | Discuss study/outcome and review limitations, transitivity, consistency, and concerns arising from network geometry. |
| 26 | Interpret results alongside other evidence and implications for research. |
| 27 | Report funding/support and funder roles, including treatment-manufacturer funding and professional conflicts of relevant content experts. |

Use alongside PRISMA 2020. These identifiers belong to the **2015 extension based on PRISMA 2009**; they are not a renumbering of PRISMA 2020. Cite “PRISMA-NMA S2”, for example, to avoid ambiguity. Rankings do not substitute for effect estimates, uncertainty or assessment of transitivity.
