# APA JARS-Quant: general checklist (2018; table revised 2020)

Quantitative psychological and behavioural research; general Table 1. Requirements restated concisely; original item numbers retained where the source numbers them. Match applicable items to manuscript evidence; reporting omissions do not establish poor study conduct.

Source: [APA JARS-Quant: general checklist (2018; table revised 2020)](https://doi.org/10.1037/amp0000191) · [Checklist source](https://journals.sagepub.com/pb-assets/cmscontent/joa/JARS-Quant-1724099515.pdf).

| Source heading | Reporting requirement |
| --- | --- |
| Title | Identify variables, their relationships, theoretical questions and population. |
| Author note | Provide registration; disclose reused or previously reported data (including dissertations/conferences), funding, conflicts, changed affiliations, corresponding-author contact and other relevant circumstances. |
| Abstract — objectives | State the problem and principal hypotheses. |
| Abstract — participants | Describe relevant sample characteristics; identify animal genus/species where applicable. |
| Abstract — methods | Summarise design, sample size, materials, outcomes and data collection; identify secondary analyses and their data sources. |
| Abstract — findings | Give principal findings with effects and uncertainty or significance levels. |
| Abstract — conclusions | State implications/applications beyond repeating results. |
| Introduction — problem | Explain theoretical or practical importance. |
| Introduction — prior scholarship | Relate the study to existing work and distinguish earlier reports of the same study. |
| Introduction — hypotheses | Specify hypotheses, aims, theory/rationale, primary/secondary hypotheses and other planned analyses; connect them to design. |
| Method — eligibility | State inclusion/exclusion criteria, including demographic restrictions. |
| Method — participant characteristics | Report key demographics and topic-specific characteristics. For animals, give species/strain, supplier/stock, number, sex, age, weight, physiological/genetic/health status, prior drug/testing exposure and procedures as relevant. |
| Method — sampling | Describe selection, sampling plan, participation proportion, self-selection, setting/dates, agreements/payments, ethical review and safety monitoring. |
| Method — sample size | Give intended and achieved sizes, power/precision justification, and interim/stopping rules. |
| Method — measures/covariates | Define primary/secondary measures and covariates, including collected measures omitted from the report. |
| Method — collection | Describe data-collection methods. |
| Method — measurement quality | Describe collector training/reliability and repeated observations where used. |
| Method — instruments | Describe validated or bespoke instruments and relevant psychometric/biometric properties. |
| Method — masking | State awareness of assignments among participants, intervention staff and assessors; if masked, explain how and whether/how success was assessed. |
| Method — psychometrics | Where possible, report reliability for analysed sample scores; give relevant convergent/discriminant validity. Include applicable interrater reliability, test–retest reliability at the study interval, and internal consistency; describe demographics of external samples supplying estimates. |
| Method — design | State manipulation or natural observation and the design name. Apply relevant experimental, observational, longitudinal, N-of-1, replication or specialised-analysis modules. |
| Method — diagnostics | Prespecify post-collection exclusions, missing-data/imputation criteria, outlier definitions/handling, distribution checks and transformations. |
| Method — analytic strategy | Describe inferential methods and experiment-wise error protection separately for primary, secondary and exploratory hypotheses. |
| Results — flow | Give group counts at every stage and participant progression, with a diagram where possible. |
| Results — recruitment | Give recruitment and repeated-measure/follow-up dates. |
| Results — missingness | Quantify missing data; give empirical/theoretical support for the assumed mechanism (MCAR/MAR/MNAR); report methods actually used. |
| Results — descriptions | For primary/secondary outcomes overall and by subgroup, give sample counts, means, SDs and other relevant summaries. |
| Results — tests | Report all inferential tests, exact P values when using NHST, and enough statistics to reconstruct tests, such as degrees of freedom and relevant mean squares. |
| Results — estimates | Provide effect estimates and confidence intervals for tests where possible; distinguish primary, secondary and exploratory results. |
| Results — complex models | Specify estimated models and associated covariance/correlation matrices; identify software/procedures/packages. Apply relevant specialised standards, including SEM where applicable. |
| Results — problems | Report convergence/solution problems, regression diagnostics and analytic anomalies, with remedies; disclose assumption/distribution problems affecting validity. |
| Results — other analyses | Report additional/adjusted analyses and distinguish planned from unplanned work. |
| Discussion — hypotheses | State support or non-support for each primary/secondary hypothesis; discuss exploratory implications and potentially uncontrolled error rates. |
| Discussion — comparisons | Explain similarities and differences from prior results. |
| Discussion — interpretation | Address bias, internal/statistical validity, measurement imprecision, multiplicity/overlapping tests, sample-size adequacy and sampling validity. |
| Discussion — generalisability | Discuss applicability to target populations and other settings, measures and times. |
| Discussion — implications | Discuss implications for research, programmes or policy. |

The source has headings, not numbered items. This entry covers general Table 1. For experiments/clinical trials, observational, longitudinal, N-of-1, replication, SEM, Bayesian analysis or meta-analysis, also consult the applicable [APA design/analysis modules](https://apastyle.apa.org/jars/quantitative); those specialised tables are not reproduced here.
