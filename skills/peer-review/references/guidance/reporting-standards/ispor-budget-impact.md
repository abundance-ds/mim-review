# ISPOR budget impact recommendations (2014)

Budget impact analysis; complements cost-effectiveness evaluation. Requirements restated concisely; original item numbers retained where the source numbers them. Match applicable items to manuscript evidence; reporting omissions do not establish poor study conduct.

Source: [ISPOR budget impact recommendations (2014)](https://doi.org/10.1016/j.jval.2013.08.2291) · [Checklist source](https://www.ispor.org/heor-resources/good-practices/article/principles-of-good-practice-for-budget-impact-analysis-ii).

| Item / topic | Reporting requirement |
| --- | --- |
| Decision setting | Specify budget holder, healthcare system, perspective, and access/reimbursement constraints. |
| Population | Estimate eligible patients over time, including entrants/exits and relevant subgroups. |
| Treatment mix | Specify current/future mixes, uptake, substitution/add-on use, combinations, and off-label use. |
| Costs | Estimate intervention, administration, monitoring, adverse-event, and condition-related costs using local quantities/prices; justify indirect-cost inclusion. |
| Timing | Justify horizon and periods; account for temporal changes; normally present undiscounted period budgets. |
| Framework | Justify calculator versus simulation; expose structure and editable inputs. |
| Uncertainty | Describe and justify uncertainty methods and scenarios; use budget-holder-informed ranges, identify their sources, and assess structural assumptions. |
| Validation | Check face validity with decision makers and verify calculations. |
| Sources | Document selection, derivations, primary collection and expert elicitation; assess limitations and the possible direction and magnitude of input-data bias. |
| Report | State objectives, epidemiology, management, clinical/economic context; provide separate tables of assumptions, inputs with sources/derivations, and outputs, plus a framework diagram and reproducible calculations. |
| Primary collection | Describe collection methods and processes; supply data-collection forms or questionnaires, where used. |
| Results | Show current/future totals and incremental resource use/costs per period, disaggregated by category; report scenario results. |
| Interpretation | Explain conclusions, limitations, adherence/off-label assumptions, and input uncertainty. |
| Delivery | Provide transparent calculations and usable documentation; distinguish budget impact from companion cost-effectiveness results. |

Sullivan SD, et al., *Value in Health* 17:5–14.
