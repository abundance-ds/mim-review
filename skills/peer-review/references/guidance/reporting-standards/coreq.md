# COREQ 2007 checklist

Qualitative interviews and focus groups. Requirements restated concisely; original item numbers retained where the source numbers them. Match applicable items to manuscript evidence; reporting omissions do not establish poor study conduct.

Source: [COREQ 2007 checklist](https://doi.org/10.1093/intqhc/mzm042) · [Checklist source](https://wellcomeopenresearch-files.f1000.com/resources/COREQ_checklist.pdf).

| Item / topic | Reporting requirement |
| --- | --- |
| 1 | Identify interviewers/facilitators. |
| 2 | Give researcher qualifications. |
| 3 | Give researchers’ occupations during fieldwork. |
| 4 | Report researchers’ gender. |
| 5 | Describe relevant experience/training. |
| 6 | Disclose prior participant relationships. |
| 7 | Explain participants’ knowledge of researchers and motivations. |
| 8 | Disclose researchers’ assumptions, interests, biases. |
| 9 | Identify methodological/theoretical orientation. |
| 10 | Explain participant sampling. |
| 11 | Describe recruitment contact. |
| 12 | Report participant count. |
| 13 | Count refusals/dropouts and explain reasons. |
| 14 | Describe collection settings. |
| 15 | Identify others present. |
| 16 | Describe sample characteristics. |
| 17 | Provide interview prompts/guides and piloting details. |
| 18 | Report repeat interviews and counts. |
| 19 | Describe recording methods. |
| 20 | Report field-note use and timing. |
| 21 | Report interview/focus-group duration. |
| 22 | Discuss saturation. |
| 23 | Report transcript return for correction/comment. |
| 24 | State coder count. |
| 25 | Describe coding structure. |
| 26 | Distinguish predefined versus emergent themes. |
| 27 | Name analysis software, if used. |
| 28 | Report participant feedback on findings. |
| 29 | Support themes with attributed participant quotations. |
| 30 | Check evidence–finding consistency. |
| 31 | Present principal themes clearly. |
| 32 | Describe divergent cases and secondary themes. |

Items 1–8: research team/reflexivity; 9–23: study design; 24–32: analysis/findings. Assess whether practices are reported, not whether every listed technique was used. The source publisher’s form misprints 2017 in its introduction; the cited original is 2007.
