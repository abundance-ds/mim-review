# SQUIRE 2.0 checklist (2015)

Healthcare quality improvement. Requirements restated concisely; original item numbers retained where the source numbers them. Match applicable items to manuscript evidence; reporting omissions do not establish poor study conduct.

Source: [SQUIRE 2.0 checklist (2015)](https://doi.org/10.1136/bmjqs-2015-004411) · [Checklist source](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5256233/fullTextXML).

| Original item | Reporting requirement |
| --- | --- |
| 1 | Identify the report as healthcare improvement. |
| 2a | Include information needed for searching and indexing. |
| 2b | Summarise background, local problem, methods, intervention, results and conclusions using the journal format or a structured abstract. |
| 3 | Describe the local problem and its significance. |
| 4 | Summarise existing knowledge and relevant studies. |
| 5 | Explain frameworks/theories, assumptions behind the intervention, and why it should work. |
| 6 | State the project’s purpose and the report’s aims. |
| 7 | Describe context considered important when introducing the intervention. |
| 8a | Describe the intervention in enough detail to reproduce it. |
| 8b | Identify the team involved. |
| 9a | Describe the approach used to assess intervention impact. |
| 9b | Explain how outcomes were attributed to the intervention. |
| 10a | Define process/outcome measures; justify selection and describe validity/reliability. |
| 10b | Describe ongoing assessment of context affecting success, failure, efficiency and cost. |
| 10c | Describe checks on data completeness and accuracy. |
| 11a | Describe qualitative/quantitative inference methods. |
| 11b | Explain assessment of variation, including time effects. |
| 12 | Describe implementation/research ethics and how issues were addressed, including formal review and potential conflicts. |
| 13a | Report initial implementation, evolution and modifications over time; use a timeline, flow chart or table as appropriate. |
| 13b | Report process measures and outcomes. |
| 13c | Describe context interacting with the intervention. |
| 13d | Report observed outcome–intervention–context associations. |
| 13e | Report unintended benefits, problems, failures and costs. |
| 13f | Describe missing data. |
| 14a | Summarise findings against rationale and aims. |
| 14b | Identify project strengths. |
| 15a | Interpret the intervention–outcome relationship. |
| 15b | Compare findings with other publications. |
| 15c | Discuss effects on people and systems. |
| 15d | Explain differences from anticipated outcomes, including contextual influences. |
| 15e | Discuss costs, strategic tradeoffs and opportunity costs. |
| 16a | Discuss limits to generalisability. |
| 16b | Discuss confounding, bias and imprecision affecting internal validity across design, methods, measurement and analysis. |
| 16c | Describe mitigation and adjustment for limitations. |
| 17a | Discuss usefulness. |
| 17b | Discuss sustainability. |
| 17c | Discuss potential transfer to other contexts. |
| 17d | Explain implications for practice and research. |
| 17e | Identify next steps. |
| 18 | Report funding and the funder’s roles in design, implementation, interpretation and reporting. |

All 18 parent items and their lettered clauses are retained in factual paraphrase. Apply relevant clauses; explain non-applicability. See the [official checklist](https://www.equator-network.org/wp-content/uploads/2012/12/SQUIRE-2.0-checklist.pdf) for source wording.
