# PRISMA-ScR 2018 checklist

Scoping reviews. Requirements restated concisely; original item numbers retained where the source numbers them. Match applicable items to manuscript evidence; reporting omissions do not establish poor study conduct.

Source: [PRISMA-ScR 2018 checklist](https://doi.org/10.7326/M18-0850) · [Checklist source](https://www.prisma-statement.org/s/PRISMA-ScR-Fillable-Checklist_10Sept2019.docx).

| Item / topic | Reporting requirement |
| --- | --- |
| 1 | Identify a scoping review. |
| 2 | Summarise background, objectives, eligibility, evidence sources, charting, findings, conclusions. |
| 3 | Explain the knowledge gap and suitability of scoping. |
| 4 | Specify questions and their population/concept/context elements. |
| 5 | Give protocol access and registration, if available. |
| 6 | Justify eligibility restrictions, including dates, language, publication status. |
| 7 | List search sources, coverage dates, and last search date. |
| 8 | Supply one reproducible database search, including limits. |
| 9 | Explain screening and eligibility decisions. |
| 10 | Describe charting forms, piloting, independence/duplication, and investigator clarification. |
| 11 | Define extracted variables, assumptions, simplifications. |
| 12 | If appraised, justify appraisal, methods, and synthesis use. |
| 13 | Explain charted-data handling and summarisation. |
| 14 | Count screening stages and exclusions with reasons; preferably diagram. |
| 15 | Cite each included source and charted characteristics. |
| 16 | If appraised, report appraisal findings. |
| 17 | Present relevant charted data per source. |
| 18 | Summarise findings against review questions. |
| 19 | Discuss concepts, themes, evidence types, and stakeholder relevance. |
| 20 | Discuss review-process limitations. |
| 21 | Interpret findings, implications, and next steps. |
| 22 | Report review and included-evidence funding; review funders’ roles. |

Items 12 and 16 are conditional, not mandatory appraisal requirements. “Sources of evidence” can include documents beyond research studies; “information sources” means where evidence was sought. Data charting means extraction.
